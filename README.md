# BioKraft

BioKraft is a responsive React website for sustainable sugarcane-bagasse tableware. It is built with Vite.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

The production build is written to `dist/`.

## Contact form

The contact form is handled by Netlify Forms. The form detector in `index.html`
must stay in sync with the form in `src/pages/Contact.jsx`; Netlify scans the
built HTML during deployment to register the form. Form submissions are not
available when running the site locally with `npm run dev`.

## Deployment

Netlify deployment settings and response headers are configured in
`netlify.toml`. Deploy the `dist/` directory generated by `npm run build`.
